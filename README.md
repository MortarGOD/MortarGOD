## 造物 / Selected work

### [LegendCompiler](https://github.com/MortarGOD/LegendCompiler)

**C++17 · SysY2021 → ARMv7-a**

2021 年编译系统设计赛项目，面向 32 位 ARM 平台。以 `Scanner → Parser → CodeGen` 串起扫描、解析与汇编代码生成。

- 编译期求值与常量折叠。
- 根据除数类型处理除法与取模优化。
- 在目标代码层进行寄存器分配。
